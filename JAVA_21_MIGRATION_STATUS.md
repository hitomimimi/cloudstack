# Java 21 Migration Status — Apache CloudStack (AT&T 4.22.0.0)

> Generated by Devin AI · May 2026
> Used Devin Wiki to understand CloudStack's 7,655-file codebase before making changes.

## Executive Summary

This document captures the baseline analysis for migrating Apache CloudStack from JDK 11 to JDK 21.
The `cs.jdk.version` property has been bumped to `21` and the CI build workflow updated.
A sandbox build of 25 modules (`-pl server -am`) compiles cleanly under OpenJDK 21.

**Key blocker**: cglib-nodep 3.3.0 is unmaintained and does not support JDK 17+.
It causes 64 test failures in `engine/schema`. Fix requires migrating to ByteBuddy.

### Known Test Failure: cglib Blocker
- **Library**: `cglib-nodep:3.3.0` (last release: 2019, unmaintained)
- **Error**: `Unsupported class file major version 65` (JDK 21 = version 65)
- **Affected**: 64 test classes in `engine/schema` (DAO tests using proxy generation)
- **Failing tests include**: `VMInstanceDaoImplTest`, `HostDaoImplTest`, `NetworkDaoImplTest`,
  `VolumeDaoImplTest`, `VMTemplateDaoImplTest`, `VMSnapshotDaoImplTest`, `SnapshotDataStoreDaoImplTest`
- **Fix**: Migrate from cglib to ByteBuddy (separate follow-up task)
